# 五子棋

网页版五子棋，支持 **人机 / 双人 / 联机** 三种模式。

## 玩

- **联机版（功能完整，推荐）**：<https://gomoku-online-53041.app.workbuddy.host/>
- **本仓库（GitHub Pages）**：<https://dalizi01.github.io/game/>

## 模式说明

- **人机**：内置 AI，三档难度。
- **双人**：同一台设备轮流落子。
- **联机**：和真人对战。可以「快速匹配」随机找对手，也可以「创建房间」拿到 4 位房间号 + 邀请链接发给朋友，对方打开链接自动进房。悔棋 / 重开需双方同意，对局结束后双方都点「再来一局」才会重开并交换先手。

## 关于联机

本仓库只是静态页面，没有服务端。而「随机匹配真人」「邀请好友」都需要一个中转方来转发落子，所以联机模式调用的是独立部署的联机服务：

```
https://gomoku-online-53041.app.workbuddy.host
```

地址写在 `index.html` 里的 `ONLINE_FALLBACK` 常量中。页面会先探测同源的 `/api/ping`，不通再用这个地址，因此同一份代码在两种部署方式下都能跑。

## 实现要点

- 单文件、无构建、无框架，棋盘用 Canvas 绘制。
- 按 `devicePixelRatio` 设置画布后备缓冲，配合 `ResizeObserver` 自适应尺寸，网格线吸附到设备像素边界，所以在系统缩放 125% / 150% 的屏幕上依然锐利。
- 棋子用径向渐变 + 投影 + 内边缘光绘制，带最近一步标记和获胜连线高亮。

## 本地运行

这个仓库只有静态页面；要跑联机服务请见部署版项目源码（`server.js`，零依赖 Node）。
纯前端部分直接双击 `index.html` 即可，人机 / 双人模式不需要服务端。
